# User Guide (short)

1. **Owner** logs into `/admin`, reviews dashboard stats from live data
2. Create **customers** and **services**
3. Create a **booking**, assign employees (conflict detection runs)
4. Staff execute the **cleaning job** (start/pause/complete)
5. **Inspector** scores the inspection; failures open corrective actions
6. Generate **invoice** and record **verified** payment
7. Customer uses `/portal` for bookings/invoices/inspection summaries
8. Toggle modules under Tenant Modules without deleting history
